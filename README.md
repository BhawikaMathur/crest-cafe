# ☕ Crest Café — Restaurant & Café Website

A modern, responsive restaurant/café website built with a cozy dark theme, showcasing the café's story, signature menu, gallery, and a table reservation form.

## 🔗 Live Demo
[View Live Site](https://bhawikamathur.github.io/crest-cafe/)

## ✨ Features
- Fully responsive layout with dedicated breakpoints for tablet and mobile screens
- Sticky navigation bar with smooth in-page section links
- Elegant dark-themed hero section with a full-width background image
- Interactive menu grid showcasing signature dishes with pricing
- Animated gallery section with an asymmetric hover effect that highlights each image
- Table reservation form with client-side validation and a confirmation alert
- Card hover animations across the menu and gallery sections for a polished user experience

## 🛠️ Tech Stack
- **HTML5** — semantic page structure
- **CSS3** — responsive styling, Flexbox layouts, media queries, and hover/transition effects
- **JavaScript** — form handling and interactive booking confirmation

## 🚀 Getting Started
Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/BhawikaMathur/crest-cafe.git
cd crest-cafe
```

Then simply open `index.html` in any web browser — no build steps or dependencies required.

## 📚 What I Learned
- Building multi-breakpoint responsive layouts using CSS media queries
- Creating an asymmetric, interactive gallery grid using Flexbox `flex-grow` on hover
- Structuring a real-world business website with distinct sections (Hero, About, Menu, Gallery, Contact)
- Handling form submissions with JavaScript event listeners and `preventDefault()`
